# Blinkit Sales Analysis Dashboard

A Power BI report analyzing grocery sales data for **Blinkit**, built to surface key performance metrics and trends across products and outlets.

## 📊 Overview

This dashboard provides a single-page summary view of sales performance, helping identify which item types, outlet formats, and locations drive the most value.

## 🔑 Key Metrics (KPIs)

- **Total Sales**
- **Average Sales**
- **Number of Items**
- **Average Rating**

## 🧩 Breakdowns / Dimensions

- Item Type
- Item Fat Content
- Item Visibility
- Outlet Type
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year

## 🛠️ Tech Stack

- **Power BI Desktop** (`.pbix`)

## 📂 Repo Contents

| File | Description |

## ▶️ How to Open

1. Download [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows only).
2. Clone or download this repository.
3. Open `Blinkit.pbix` in Power BI Desktop.
